# Company logos

Drop a square logo for each company in this folder with these exact names:

| Company | File name |
| --- | --- |
| Ernst & Young | `ey.png` |
| Bloomerang | `bloomerang.png` |
| Wayfair | `wayfair.png` |
| Fidelity Investments | `fidelity.png` |
| Boston After School & Beyond | `basb.png` |

Easiest source: open the company's LinkedIn page, right-click the square logo, and choose
**Save Image As…**. Any square PNG or JPG works (200×200 or larger looks sharp).
If you use a .jpg or .svg instead, change the `logo:` path for that job in `js/profile.js`.

Until a file is here, the page shows a tile with the company's initials instead.
